# Roshni's Diet Tracker

A single-file, offline-first tracker for the Truweight High Protein phase diet plan
(29-01-2026 → 12-02-2026, dietician: Qamar Jahan).

## How to use

Just open `index.html` in any browser — no install, no server, no account.

- **On your phone:** send yourself the file (email/WhatsApp/Drive), open it in Chrome or
  Safari, then use "Add to Home Screen" so it opens like an app.
- **On a laptop:** double-click the file.

All data is stored in the browser's local storage on your device. Use
**Guide → Backup data** to download a JSON backup, and **Restore backup** to load it on
another device.

## What it tracks

- **Daily meal checklist** — all 7 meal slots (waking up → bedtime) for each of the 4
  plans in the diet chart (Plans 1–3 Regular, Plan 4 Weekly Detox). "OR" alternatives
  from the chart are shown as tappable choices. The plan auto-rotates 1 → 2 → 3 each
  day; pick Plan 4 manually on your detox day.
- **Water intake** — tap glasses or +250 ml, with the phase's 3-litre daily minimum.
- **Weight** — log daily weight, see start/latest/change and a trend chart.
- **Guidelines** — the key High Protein phase rules condensed from the plan PDF.
- **Streak** — consecutive days with at least 5 of 7 meals completed.
